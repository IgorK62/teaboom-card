# Тестовое задание Teaboom.ru — карточка товара «Ананасовый улун»

Вёрстка верхней части карточки товара: изображение, название, категория,
выбор фасовки, артикул, актуальная цена, старая цена при наличии скидки,
кнопка «В корзину», блок с коротким описанием.

## Запуск

Сборка не требуется — готовая вёрстка лежит в репозитории.
Откройте `index.html` в браузере (двойной клик или `file://`).

## Разработка (SCSS)

Скомпилированный CSS лежит в `css/styles.css`, исходники — в `scss/`.
Для правки стилей запустите слежение:

```bash
npx sass scss/main.scss css/styles.css --watch
```

## Семантика и БЭМ

- строгий БЭМ: `.media`, `.price`, `.pack`, `.button`, `.description`,
  `.category`, `.sku` — самостоятельные блоки (файл на блок);
  `.product` владеет только раскладкой и задаёт вертикальный ритм
  через **миксы** (`.price.product__price`); модификаторы —
  `.button--primary`, `.button--added`, состояние `.price.is-updated`;
- семантический HTML5: `article`, `figure`, `header`, `section`,
  `fieldset + legend`, `h1/h2`, `<s>` для неактуальной цены;
- микроданные Schema.org `Product` + `Offer` (цена, валюта, sku,
  наличие) — обновляются скриптом вместе с интерфейсом;
- доступность: фасовки — нативные `radio` (стрелки, пробел), видимый
  фокус, `aria-live` на цене, «Старая цена:» для скринридеров
  (`visually-hidden`), `prefers-reduced-motion`.

## Функциональность (по заданию)

- переключение фасовки **100 г / 500 г / 1000 г / 5000 г** обновляет
  цену, старую цену, артикул и выбранное состояние плитки;
- бейдж скидки на фото пересчитывается автоматически (−7…−27 %);
- кнопка «В корзину» имеет обычное состояние и состояние при наведении
  (плюс нажатие и короткий отклик «Добавлено ✓» — реальную корзину
  подключать не требуется);
- адаптивность: **1440 / 768 / 375** — Grid + Flexbox; на планшете и
  мобильном карточка перестраивается в одну колонку, плитки фасовок —
  в сетку 2×2.

## Производительность

- ноль внешних запросов: системные шрифты, один CSS (~6 КБ) и один JS
  (~3 КБ), одно изображение (JPEG; формат корректно совпадает с расширением);
- LCP-изображение: `rel=preload` + `fetchpriority="high"` на `<img>`;
- `width`/`height` у изображения — нулевой layout shift (CLS);
- скрипт подключён с `defer`, не блокирует рендер.

## Технологии

HTML5 · SCSS (`@use`-модули, карты, миксины) · vanilla JavaScript ·
BEM · Flexbox/Grid. Без фреймворков, Bootstrap и готовых шаблонов.
